# **Supply Chain Analysis**

A data analysis project focused on exploring supply chain operations, sales trends, shipping performance, and delivery efficiency using Python.

# **Technologies Used**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# **Project Structure**

`DescriptionDataCoSupplyChain.csv` — Supply chain dataset
`Supply Chain Analysis.ipynb` — Data analysis and visualizations
`Supply Chain Analysis Report.pdf` — Project report


# **Objectives**
- Analyze sales and order trends.
- Evaluate shipping and delivery performance.
- Identify patterns in delivery delays.
- Discover insights to improve supply chain efficiency.
